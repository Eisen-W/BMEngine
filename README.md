# madokascript-EWE
my custom scripting language but for my 2D game engine's specific use cases

### Subtree for updates from core [MadokaScript](https://github.com/Eisen-W/madokaScript)
``` shell
cd madokascript-EWE
git remote add base-upstream https://github.com/Eisen-W/madokaScript.git
git subtree pull --prefix=base/ base-upstream main --squash
```
